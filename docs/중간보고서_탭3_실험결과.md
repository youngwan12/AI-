중간보고서 탭 3에 적힌 순서(변수 분석 → 실험 A~E → Random Forest / CatBoost 비교)를 그대로 수행한 결과입니다.
탭 2 계획서에 있는 Logistic Regression도 같이 돌려 세 모델을 비교했습니다.

- 코드: `src/variable_analysis.py`, `src/group_experiments.py`(랜덤 분할 / `--customer-split` 고객 단위 분할), `src/group_noise_check.py`(반복 검증), `src/plot_groups.py`

- 검증: 두 가지로 모두 돌림. 지표는 LogLoss(낮을수록 좋음)
  - **랜덤 분할** Stratified 5-Fold (shuffle, seed 42): DACON test와 같은 조건 (test의 88%가 train에 있는 고객)
  - **고객 단위 분할** GroupKFold(5): 검증 고객이 전부 처음 보는 사람. 탭 2의 '중복 입력 기록에 의한 평가 편향' 검토용
- 비교 기준: 클래스 비율로만 찍기 0.8824, DACON 공식 Baseline 1.0738 (탭 2에서 직접 돌린 값은 1.0715)

## 3. 해석

1. **신용등급을 실제로 알려주는 정보는 카드 발급 경과 기간(begin_month)이 거의 전부입니다.** 고객 단위 분할에서 C(변수 2개)만 쓴 CatBoost가 18개를 다 쓴 A보다 오히려 약간 좋습니다(3회 반복 평균 0.8090 vs 0.8104). 나머지 변수가 정보 없이 잡음만 더한다는 뜻입니다. C를 빼면 찍기 수준(0.8819)으로 떨어집니다. 변수 분석에서 begin_month만 뚜렷한 차이를 보인 것과 일치합니다.
2. **소득·고용, 자산·가족 변수는 처음 보는 고객에 대해서는 정보가 거의 없습니다.** 고객 단위 분할에서 B와 D만 쓰면 찍기(0.8824)와 같고, A에서 빼도 점수가 변하지 않습니다. 변수 분석에서 소득 차이가 1%였던 것과 맞습니다.
3. **랜덤 분할에서 소득·고용(B)이 효과가 있어 보인 것은 '같은 고객 알아보기' 때문입니다.** Random Forest의 B 점수가 랜덤 분할 0.7987에서 고객 단위 분할 0.9502(찍기보다 나쁨)로 무너집니다. 소득·근속일수 같은 정확한 숫자 조합이 고객을 식별하는 열쇠 역할을 한 것입니다.
4. **Random Forest는 고객을 외우는 경향이 강합니다.** 랜덤 분할에서는 Random Forest가 CatBoost보다 좋지만(0.7200 vs 0.7516), 고객 단위 분할에서는 CatBoost가 앞섭니다(0.8108 vs 0.8280). C 단독 Random Forest는 두 분할 모두 찍기보다 나쁩니다(0.9143, 0.9670). 나이처럼 사람마다 거의 고유한 값을 외워 버리기 때문입니다.
5. **파생변수(E)는 CatBoost에 소폭 도움이 됩니다.** 랜덤 분할 0.7516 → 0.7412, 고객 단위 분할 0.8104 → 0.8058(3회 반복 평균, 우연이 아닌 차이).
6. **고객 식별키(E+)는 기존 고객에게만 효과가 있습니다.** 랜덤 분할에서는 0.6746으로 최고이고 DACON 공식 Baseline(1.0738) 대비 37% 낮습니다. 고객 단위 분할에서는 0.8073으로 E와 같습니다. DACON test는 88%가 train에 있는 고객이라 0.67대 점수가 test 성능을 대변하고, 처음 보는 고객이라면 0.81 수준을 기대해야 합니다.
7. 탭 3의 "Random Forest를 기준 모델로 먼저 학습하고 CatBoost로 개선" 계획은, **처음 보는 고객 기준(고객 단위 분할)으로는 그대로 성립하고**, 기존 고객 기준(랜덤 분할)에서는 고객 식별키를 넣었을 때 성립합니다.

## 4. 점수 신뢰성 점검 (`src/validity_check.py`)

- 조기 종료 시점을 검증 fold로 고른 영향: CatBoost E+ 0.6746 → 0.6755 (학습 fold 안에서 시점을 고르고 전체 재학습). 영향 거의 없음
- 앙상블 가중치를 같은 OOF로 고른 영향: 0.6717 → 0.6717. 영향 없음
